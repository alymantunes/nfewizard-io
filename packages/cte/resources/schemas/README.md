# Schemas oficiais do CT-e

Este diretório contém os XSD oficiais do CT-e 4.00, publicados no pacote vigente em 08/06/2026 (NT 2026.001 v1.01 corrigida), incluindo os tipos da Reforma Tributária (IBS/CBS). A validação local usa a cadeia de includes/imports deste pacote antes de autorizar o envio.

Fonte: [Portal Nacional do CT-e — schemas](https://hom.cte.fazenda.gov.br/portal/listaConteudo.aspx?tipoConteudo=0xlG1bdBass%3D). Referência de transporte e conteúdo: [MOC CT-e 4.00](https://www.cte.fazenda.gov.br/portal/exibirArquivo.aspx?conteudo=0eu1YksSGXM%3D) e [NT 2026.002 v1.00](https://www.cte.fazenda.gov.br/portal/exibirArquivo.aspx?conteudo=sMeQcKKmGXE%3D).
